# Notes

## What is Markdown?
Markdown is a **markup language** used to format plain text.  
It allows you to create styled documents with:  
- Headings  
- Bullet points  
- Bold and italic text  
- Links and images  

## What is Git?
Git is a **version control system** that helps developers track changes in their code.  
## Uses: 
- Save different versions of a project  
- Go Back to old versions  
- Collaborate with others 

## What is GitHub?
GitHub is an **online platform** that hosts Git repositories.  
## tools:  
- Collaboration and code sharing  
- Pull requests and code reviews  
- Issue tracking and project management  

## What is Slack?
Slack is a **team communication platform** used for collaboration.  
## Features: 
- Channels for organizing conversations  
- Direct messaging  
- File sharing and integrations with other tools
