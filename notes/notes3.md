# Notes 3

## Part 1

### What is a Graphical User Interface (GUI)?
A GUI lets users interact with the computer with windows, icons...

### What is a Desktop Environment?
A desktop environment is a graphical workspace.

### What is the Command Line Interface (CLI)?
The CLI lets users type text commands to control the system and perform tasks.

### How do I Access the Command Line Interface (CLI)?
You can open the terminal or pressing **Ctrl + Alt + T** in most Linux distributions.

### What is a Virtual Console?
A virtual console is a full-screen text interface.

### What is a Terminal Emulator?
A terminal emulator is a program inside the GUI that lets you use the command line(Tilix).

### What is Bash?
Bash (Bourne Again Shell) is a popular command-line shell used to run commands and scripts.

### What is the Shell Prompt?
The shell prompt is the text or symbol that shows it’s ready for a command.

# Part 2

## Definition, usage, and examples of the following commands

### clear  
**Definition:** Clears the terminal screen.  
**Usage:** `clear`  
**Example:** `clear`

### echo  
**Definition:** Prints text or variables.  
**Usage:** `echo [text]`  
**Example:** `echo Hello`

### date  
**Definition:** Shows date and time.  
**Usage:** `date`  
**Example:** `date`

### free  
**Definition:** Displays memory usage.  
**Usage:** `free -h`  
**Example:** `free -h`

### uname  
**Definition:** Shows system info.  
**Usage:** `uname -a`  
**Example:** `uname -a`

### history  
**Definition:** Lists previous commands.  
**Usage:** `history`  
**Example:** `history`

### man  
**Definition:** Opens a command’s manual.  
**Usage:** `man [command]`  
**Example:** `man ls`

### tldr  
**Definition:** Shows simple command examples.  
**Usage:** `tldr [command]`  
**Example:** `tldr cp`

### cheat  
**Definition:** Displays quick command notes.  
**Usage:** `cheat [command]`  
**Example:** `cheat tar`

### hostname  
**Definition:** Shows the computer’s name.  
**Usage:** `hostname`  
**Example:** `hostname`

### df  
**Definition:** Shows disk space usage.  
**Usage:** `df -h`  
**Example:** `df -h`

### du  
**Definition:** Shows directory sizes.  
**Usage:** `du -h [path]`  
**Example:** `du -h /home`

### figlet  
**Definition:** Creates big text banners.  
**Usage:** `figlet [text]`  
**Example:** `figlet Linux`
