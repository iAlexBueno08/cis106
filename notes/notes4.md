# APT and Shell Script Guide

## Using APT

Update:
sudo apt update
sudo apt upgrade

Install:
sudo apt install packagename

Remove:
sudo apt remove packagename

Purge:
sudo apt purge packagename

Clean:
sudo apt autoremove
sudo apt clean

## Shell Script Steps

1. Create file:
   <file_name>.sh
2. Add:
   #!/bin/bash
   echo "Hello"
3. Save and exit
4. Open Terminal in Folder
5. Run:
   bash ~/<Folder_name>/<File_name.sh>
